# 项目架构

## 仓库边界

- `app/` 是可独立构建的 Flutter 应用。
- `docs/` 保存产品和技术设计。
- `developer-guide/` 保存开发者环境搭建、构建及协作流程。

## 应用结构

当前应用规模较小，入口位于 `app/lib/main.dart`。随着功能增加，建议逐步按职责拆分：

```text
lib/
├── core/       # 通用基础能力
├── features/   # 按业务功能组织的模块
├── shared/     # 跨功能复用的组件
└── main.dart   # 应用入口
```

目录应随实际需求演进，不提前创建没有内容的业务层级。
