# 开发者指南

`developer-guide/` 面向参与项目的开发者，提供可以直接照做的环境搭建、构建和协作说明。

- [环境搭建](getting-started.md)
- [Web 构建指南（无需 Xcode）](web-build.md)
- [Xcode 构建指南](xcode-build.md)
- [协作流程](collaboration.md)

没有 Mac 或 Xcode 的开发者可以完成 Flutter Web 的开发、Chrome 调试和 Release 构建，请直接阅读 [Web 构建指南](web-build.md)。生成 iOS 应用、运行 iOS 模拟器以及签名发布仍需要 macOS 和 Xcode。

产品需求、架构设计和技术决策统一存放在 [`docs/`](../docs/README.md)。
